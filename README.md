# Protagonist Labs — Scoop bucket

Free Windows apps from [Protagonist Labs](https://protagonistlabs.app/).

```powershell
scoop bucket add protagonist https://github.com/limburatorul/scoop-bucket
scoop install protagonist/lume
scoop install protagonist/steamradar
scoop install protagonist/auto-clicker
```

| App | What it does |
|---|---|
| [Lume](https://protagonistlabs.app/lume/) | Keyboard launcher: Alt+Space, a few letters, Enter. MIT. |
| [SteamRadar](https://protagonistlabs.app/steamradar/) | Alerts when a Steam, GOG or Epic game goes free or drops under your price. GPL-3.0. |
| [Auto Clicker](https://protagonistlabs.app/autoclicker/) | Intervals down to 1 ms, routes of points, scripts that wait for an image. GPL-3.0. |

The same apps are also on winget as `ProtagonistLabs.Lume`, `ProtagonistLabs.SteamRadar` and `ProtagonistLabs.AutoClicker`.
